# Tienda en Marcha · Simulador de consultoría

Demo 3D interactiva de **Actio Growth**: una tienda de barrio en estilo diorama donde las visitas que llegan por anuncios pagos u orgánico se topan con cuellos de botella en Marketing, Ventas, Operaciones / Servicios y Finanzas. Al aplicar la consultoría en cada área, el flujo se libera y se traduce en ganancias.

**Ver la demo:** https://actiogrowth.github.io/consultoria-3d/

- Sin paso de build: HTML + CSS + JS (módulos ES) y Three.js 0.160.0 desde CDN.
- Para probar en local, sirve la carpeta con cualquier servidor estático, por ejemplo `python -m http.server`.
- Textos editables en `js/config.js` (`TEXTOS`).
